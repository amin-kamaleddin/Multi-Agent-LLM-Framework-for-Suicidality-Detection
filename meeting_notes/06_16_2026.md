Project Goal and Scope
Research paper on multi-agent LLM framework for suicidality detection in text
Not a deployable clinical tool: performance bar (99% accuracy, zero false negatives) is too high for this phase
Value proposition: detect suicidal ideation in social media/chat text before someone seeks help
Prior team tested 10+ individual LLMs, averaged ~60-70% accuracy; this work builds on that as a baseline
Multi-Agent Framework Designs
Two designs discussed as starting points:
Four specialized agents (one per suicidality phase) reporting to one generalist “judge” LLM -> Ming Xuan's possible work
Hierarchical decision-tree structure: agents branch on risk/no-risk at each stage -> Agilan's proposed design
Output: binary yes/no flag per phase of suicidality, not a single four-class label
Confidence scoring: ask each LLM for a 1-100 confidence score alongside its flag
Hypothesis: LLM self-reported confidence correlates positively with accuracy
Low-confidence outputs can be abstained or escalated to a stronger/more expensive model/human validation
Negative results are publishable: all tested designs will be reported, not just the best one
Comparison benchmarks:
Rule-based keyword engine (kill, harm, knife, pills, etc.)
Single-agent LLM baseline (replicating prior team’s results)
Multiple multi-agent designs against each other
